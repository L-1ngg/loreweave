[Spec #29](https://github.com/L-1ngg/loreweave/issues/29)

## What to build

The owner asks without choosing files or selects several for comparison, gets ambiguity/evidence/coverage outcomes honestly, and asks follow-ups whose intent uses history while new facts still use current-run original pages.

## Acceptance criteria

- [ ] Omitted selection discovers current authorized candidates through paginated metadata; explicit nonempty selection is enforced as an allowlist on all reads/citations and an empty list is invalid.
- [ ] Clearly matching candidates can proceed; equally plausible intended targets produce clarification, and bounded discovery does not claim exhaustive original-content coverage.
- [ ] Persist library/selected scope for follow-ups; candidates found in one library-mode run do not silently narrow later questions.
- [ ] Pin explicit selected versions at acceptance and library candidates on first substantive read; preserve each run's bindings while new questions recheck current visibility/eligibility/versions.
- [ ] Evaluate the 20-page reading boundary per document in mixed-length scopes, with original-backed multi-document attribution, qualifiers and unresolved source conflicts.
- [ ] Use canonical history to resolve abbreviated subject/year intent; unsupported prior assistant assertions cannot replace original-page evidence.
- [ ] Compatible cached/stored page content is reusable without reparsing, after current checks and a new run read record; returned citations remain resolvable under that run.
- [ ] Evidence gaps, incomplete discovery/reading and finite-budget exhaustion are distinct outcomes, verified through shared QA/public HTTP and browser follow-up workflows.
