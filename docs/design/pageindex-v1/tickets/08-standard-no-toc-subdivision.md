# P08: Complete Standard without a printed TOC

**Status:** published snapshot; the live GitHub work item owns execution state.

**Live work item:** [#37](https://github.com/L-1ngg/loreweave/issues/37)

## Parent

[Spec #29](https://github.com/L-1ngg/loreweave/issues/29)

## What to build

Standard indexes documents without a usable printed TOC and subdivides oversized sections within verified bounds, completing the second indexing mode through the same Web and publication workflow.

## Acceptance criteria

- [ ] Construct no-TOC headings/hierarchy from bounded original-page windows with typed model outputs and original-location verification; do not use a Flash fallback.
- [ ] Merge/window candidates without losing front matter, references, qualifications or physical-page reachability.
- [ ] Implement bounded section subdivision for oversized nodes, including depth/call/context/time exhaustion and schema/range failures.
- [ ] Complete mapping verification/repair edge cases and valid same-page boundaries across both Standard paths.
- [ ] Generate default summaries from the final structure and publish only fully validated artifacts; failures remain inspectable and cannot activate a partial tree.
- [ ] The same page/tree contract and Web mode/progress/viewer controls work for Flash and both Standard paths without additional first-version switches.
- [ ] Compare representative accepted/refused cases with the fixed Standard reference and disclose extraction/model defects, budgets and import coverage.
