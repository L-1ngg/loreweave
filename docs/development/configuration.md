# Configuration

[setup.ts](../../scripts/setup.ts) creates `.pageindex.env` with mode `0600` and
preserves an existing file. [configuration.ts](../../scripts/configuration.ts)
loads only `LOREWEAVE_*` entries; process environment wins over file values.
`LOREWEAVE_CONFIG_FILE` selects another private file. Legacy configuration and
knowledge data are never loaded automatically.

## Runtime settings

| Variable                       | Meaning / setup default                                                              |
| ------------------------------ | ------------------------------------------------------------------------------------ |
| `LOREWEAVE_DATABASE_URL`       | PostgreSQL URL; setup uses `loreweave_pageindex` at port 45434                       |
| `LOREWEAVE_ARTIFACT_DIRECTORY` | Original storage; setup uses `.pageindex-data/originals`                             |
| `LOREWEAVE_ACCESS_PASSWORD`    | Owner Web password, at least 12 characters; randomly generated by setup              |
| `LOREWEAVE_SECRET_KEY`         | 64 hexadecimal characters used to wrap saved model keys; randomly generated by setup |
| `LOREWEAVE_MODE`               | `real` for actual connections; setup selects loopback-only `fixture` for development |
| `LOREWEAVE_PORT`               | Requested local port, normally 41737; occupied ports are preserved                   |
| `LOREWEAVE_BUILD_DIRECTORY`    | Compiled Start build directory, default `dist`                                       |

The database name must start with `loreweave_pageindex`. Use its independent schema
and migrations. Back up the database, originals and wrapping key together in
private storage; replacing the wrapping key does not re-encrypt existing saved
credentials. Set/verify model connections and roles through
[Settings](../guides/settings-and-mcp.md), not browser environment variables.

## Captured work bounds

Defaults are positive integers validated by [models.ts](../../src/server/models.ts)
and captured per accepted attempt/run. Settings has no budget UI.

| Variable                     | Default | Meaning                                   |
| ---------------------------- | ------: | ----------------------------------------- |
| `LOREWEAVE_INDEX_CALLS`      |     120 | Index model requests, including failures  |
| `LOREWEAVE_QA_CALLS`         |      16 | QA model requests across iterations       |
| `LOREWEAVE_QA_TOOL_CALLS`    |      60 | QA tool invocations                       |
| `LOREWEAVE_INDEX_PAGES`      |    2000 | Physical pages per index attempt          |
| `LOREWEAVE_QA_PAGES`         |     160 | QA page reads, including cache reuse      |
| `LOREWEAVE_CONTEXT_CHARS`    |   60000 | Original/model-request context characters |
| `LOREWEAVE_OUTPUT_CHARS`     |  100000 | Delivered answer characters               |
| `LOREWEAVE_INDEX_TIMEOUT_MS` | 1800000 | Index elapsed-work bound                  |
| `LOREWEAVE_QA_TIMEOUT_MS`    |  180000 | QA elapsed-work bound                     |

Provider adapter retries are disabled. Each request has at most 120 seconds of
adapter timeout. Role verification has a finite captured deadline capped at 180
seconds. Exhaustion produces explicit failure/incompleteness, not exhaustive
absence. These work bounds are not provider-independent USD caps or remote
termination guarantees.

Import accepts at most 50 MiB. Library/tree pages contain at most 50 records;
tree output is additionally limited to 12,000 serialized characters. A page read
accepts at most eight physical pages and returns at most 18,000 text characters
with explicit continuation. Selected scope contains at most 30 documents.
Construction/summary windows contain at most eight pages and obey context bounds.
A page that cannot fit is refused explicitly.

The process uses one index worker and an eight-connection database pool. One Web
conversation permits one active run; distinct conversations and MCP questions can
run concurrently. This is not a provider-wide quota or a throughput guarantee.

## Development outputs

Tests/measurements write to `.pageindex-data/evaluation/runs/<invocation>/` by
default. `LOREWEAVE_EVALUATION_OUTPUT_DIRECTORY` can select another ignored run
directory or an external directory. The artifact helper refuses destinations
elsewhere in this repository, including tracked documents/fixtures and symlink aliases to
them. Playwright's own traces/results also remain ignored.

[Evaluation](evaluation.md) lists the input/output overrides and explicitly paid
commands. Private provider files, originals and configuration stay outside Git.
